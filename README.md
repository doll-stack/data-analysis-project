# Olympic Games Data Analysis

## Project Overview

Olympic Games Data Analysis is a data visualisation project developed using Tableau Public. It explores Olympic medal records across sports, teams, genders, seasons, years, and host cities.

The project transforms the dataset into visualisations, an interactive dashboard, and a Tableau Story to make comparisons and trends easier to understand.

## Objectives

- Analyse Olympic medal-record distributions across different sports.
- Compare medal records across Olympic teams.
- Explore medal-record trends over time.
- Compare medal records by gender and season.
- Identify cities with the highest recorded medal totals.
- Present findings through a Tableau dashboard and Story.
